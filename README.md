# Что такое WRP.ai?
Это специальный сайт которые служит заменой всем известной программе character.ai которая позволяет бесплатно RP отыгрывать с ИИ ботами без ограничений и проверки паспорта.

## Как работает работа с токенами?
Для работы сервиса мы используем систему токен-реверсинг, мы берем бесплатные токены от Ollama и крутим их по кругу и передаем запросы через разные токены с очередями.
На данный момент есть 3 токена которые крутятся между собой и находятся в .env файле.

Пример .env
```
OLLAMA_API_KEY_Alpha= - - - token 1 - - -
OLLAMA_API_KEY_Delta= - - - token 2 - - -
OLLAMA_API_KEY_Moon= - - - token 3 - - -
```

Можно заметить что после OLLAMA_API_KEY идет какое то название, это название лично я обозвал сервером, при входе на страницу servers.html и просмотра использования токенов то имя сервера будет браться именно из этой вставки.

## Безопасна ли переписка?
Да, переписка в WRP.ai полностью безопасная и к ней никто не имеет доступа кроме самого пользователя.

Хоть сайт и был написан при помощи группы рабов ( нейросетей под моим руководством ) но он все равно безопасный из за нескольких причин:
1. Я использую .env файл и не храню токены в открытом виде
2. Каждое сообщение которое присылается на сайте хешируется при помощи sha ключа и хранится ввиде хеша
3. Хорошо настроенные firebase rules и права доступа
